## Source Provenance

Phase 0 research reviewed several open-source projects, including
PCManFM-Qt, File Commander, QDirStat, dupeGuru, QtHashSum, Mouzi,
Straw Backup, and Organizer. No source code from those projects is copied
into FilePilot. Their designs were used only as implementation references.
